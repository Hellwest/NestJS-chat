# NestJS chat

## Description

Simple NestJS + ReactJS text chat

## Features

* Room conversation
* User-to-user conversation
* User groups conversation
* Private chats with messages disappearing after a certain time period
* Avatar uploading

## Technologies

* GraphQL
* Mongoose
* MongoDB
* Websocket messaging
* Jest
* RabbitMQ
* Docker

## Launch

```bash
* docker compose up -d

* yarn workspace api start:dev
```
